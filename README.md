# WayzDWeatherTT

WayzDWeatherTT is a weather web application built to provide real-time weather conditions and forecasts for locations across the world.
This app uses your location to display local weather information and also allows you to search for weather conditions in other places.

# Features
- Location-based weather
- Location search
- Current temperature and feels-like temperature
- Current weather conditions
- Rain and precipitation information
- Wind direction information
- Humidity
- UV index
- Sunrise and sunset times
- Moonrise, moonset and moon phase
- 7-day forecast
- Day and night weather icons
- Responsive design
- Time-based colour theme

# Technologies
- HTML, CSS, JavaScript
- <a href="https://open-meteo.com/en/docs/geocoding-api">Open-Meteo API</a>
- <a href="https://nominatim.openstreetmap.org/">Nominatim API</a>
- Vite

# Purpose
WayzDWeatherTT was created as a personal project to learn all about APIs and asynchronous programming, as well as to enhance and expand my current JavaScript knowledge.
